# q3_{kr,us}.csv — 만료 후 재제출 — 방법

대상: Q2 와 같은 미체결 LIMIT BUY(같은 제외 규칙). crypto: 입력에 주문이 없어 계산 불가(`q3_crypto.csv`; 브리프의 72시간 규칙은 주문 데이터가 들어오면 적용).

## 변형
최초 **절대 지정가를 그대로** 유지하고 만료(`canceled_at`) 후 다음 **3개 정규 세션**에 재제출.
- KR: KRX 정규장 3세션. **NXT/애프터는 포함하지 않는다**(공개 일봉에 없음). 만료 구분 `kr_1530_regular_close`(15:3x 만료, 정규장 DAY) / `kr_2000_nxt_close`(20:0x 만료 — 원 주문이 이미 NXT 를 거침).
- US: 다음 3 정규 세션(ET). 만료는 전부 08:50 KST.
- 세션 = 일봉의 시가 시각이 만료 시각 이후인 봉. 3세션이 다 관측되지 않았는데 미체결이면 `censored`(분모 제외).

## 체결 가정 (`scenario`)
세션 전체를 쓰므로 창 차이는 없고 규칙만 다르다: optimistic = 저가 ≤ 지정가, conservative = 저가 ≤ 지정가 − 1틱.

## 지표
- `extra_fill_rate`: 재제출로 3세션 안에 체결된 비율(Wilson + 종목 군집). `fill_in_session_k` = 체결까지 걸린 세션 수 분포.
- 갭: 체결 세션의 시가 ≤ 지정가면 **시가에 체결**(갭다운 체결, `gap_down_fill_k`). `gapfill_open_vs_anchor_pct_*` = 시가/지정가 − 1(가격 개선폭), `gapfill_close_vs_open_pct` = 그 세션 종가/시가 − 1(시가 대비 당일 손익).
- 수익: 체결 세션 = day 0, 체결가 기준 day+5/+20 종가.
- `n_actual_rebuy_within_3`: 같은 3세션 안에 라이브 시스템이 실제로 같은 종목 BUY 를 다시 낸 건수(일일 재생성) — 이 변형과 실제 운영이 겹치는 정도.
