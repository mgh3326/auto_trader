# hk 5624 매수 진입 방식 모의 비교 실험 사전등록

같은 매수 결정에 기존 깊은 지정가와 첫 정규장 시가 지정가를 각각 적용해 모의 계좌에서 비교한다. 이 문서와 ROB-1429 등록은 초안이며, 구현과 봉인은 후속 작업에서 한다.

## 1. 가설과 비교 조건

**가설 하나** — 첫 정규장 시가 지정가는 기존 깊은 지정가보다 동일 후보·동일 예약자본 기준 비용 차감 5거래일 평가손익률을 높인다. 주 지표의 최소 효과는 시장별 평균 짝 차이 +0.25%p로 제안한다.

hk 5624의 11/13 거절 후보 11건 회고에서 첫 시가 대비 −3% 접촉은 상승 4건 중 0건, 보합·하락 7건 중 7건이었다. 닿기를 기다리는 방식이 상승 후보를 놓칠 수 있다는 탐색 근거로 시가를 택한다. 5일 가격 접촉 집계는 DAY 주문의 체결 증거로 사용할 수 없다. 회고 전체를 시험 기간에서 제외한다.

- **A** — 결정 시 저장한 기존 지지선·깊이 기준의 지정가를 유지한다.
- **B** — 결정 이후 개장하는 첫 정규장 시가를 지정가로 한 번 사용한다. 두 브로커 공통 허용 호가에 맞춰 매수 가격을 내림한다. 개장 경매 이후 시가가 수신된 시각을 기록하고, 그 뒤에만 두 주문을 사람이 제출한다. 개장가 체결을 가정하지 않는다. 수신·제출 기한은 개장 후 15분, 목표 제출 시각 차는 60초 이내다. 공통 사전 조건을 못 맞추면 두 다리를 차단한다. 한쪽 제출 뒤 실패하거나 60초를 넘기면 이미 발생한 주문과 결과를 보존하고 이탈을 기록한다. 동시 체결이 보장되는 주문으로 취급하지 않는다.
- 시장 내 두 주문에 같은 정규장 DAY 범위를 적용하고 가격 변경·시간외·익일 이월·대체 주문을 금지한다. 두 브로커에서 동일한 DAY 범위가 검증되어야 시작한다. 비교를 위해 A도 같은 제출 시점에 둔다. 이 결과는 공통 시점의 가격 규칙을 비교한다.
- 후보 필터, 청산·손절·목표·보유 규칙은 그대로 사용한다. 5거래일 평가는 관측용이며 청산 주문을 만들지 않는다. 실제 조기 청산은 기존 규칙과 양성 체결 증거를 적용한다.

## 2. 짝과 상태

짝 키는 `(epoch_id, market, review.decision_evidence.decision_id)`다. 결정에 저장된 BUY 방향, 심볼, 정책 버전·해시, `decided_at`, 원본 `proposal_id` 또는 `report_item_uuid`를 보존한다. 제안은 저장된 `order_proposals.decision_id`로, KIS 미러는 결정의 `report_item_uuid`로 연결한다. 종목·날짜·가격 유사도 추정은 결속에 사용하지 않는다. 같은 결정의 제안 재발행은 기존 짝에 귀속한다. 저장된 링크가 없거나 충돌하면 차단 사유로 집계한다.

대상은 기존 필터를 적용한 뒤 저장된 BUY 결정 중 원본 깊은 지정가와 승인 가능 수량 또는 금액이 확인되는 단일 주문 후보로 한정한다. 분할 주문을 한 주문으로 합치지 않는다. 링크 누락, 단일 주문 조건 불충족, 양쪽 계좌의 공통 정규장·호가·종목·잔고 조건 불충족은 원본 모집 흐름에서 별도 집계한다. 과거 거절 후보를 다시 내지 않는다. 두 계좌의 같은 종목에 이미 열린 실험 포지션이나 미확정 주문이 있으면 신규 짝은 공통 차단한다.

- 개장가를 안 뒤 제출 전에 공통 예약 한도 `C`를 결정의 승인 가능 금액과 양쪽 가용액·기존 제한 중 가장 작은 값으로 고정한다. 결정이 수량만 저장한 경우 원래 수량×A 지정가를 금액 상한으로 사용한다. 비용 여유를 포함한 두 주문 중 높은 주당 예상 비용으로 `C`를 나누어 공통 정수 수량을 내림한다. 원래 수량 상한도 적용한다. 1주 미만이면 양쪽 차단한다. 예약 기준은 양쪽에 동일한 `C`를 쓰며 주문 금액 차이와 미사용 현금을 각각 남긴다. KRW와 USD를 합산하지 않는다.
- 짝마다 A·B 한 다리씩을 전송 전에 내구 기록한다. `(짝 키, arm)`을 유일하게 관리하고 기존 브로커 예약·멱등키·정규화 주문번호를 연결한다. 중복 호출은 기존 상태를 반환한다. 주문 접수가 불명확하면 `UNKNOWN`으로 보류하고 기존 대사로만 확인한다. 반대쪽을 맞추기 위한 재발송·재가격·잔량 주문을 금지한다.
- 한쪽만 체결되면 짝을 유지한다. 체결된 쪽은 실제 체결 수량만 기존 청산 규칙에 넘긴다. 관측 완전성이 확인된 무체결·전송 전 차단은 현금 손익 0이며, 두 상태는 구분해서 표시한다. 계좌 상태나 관측이 불명확하면 0을 기록하지 않는다. 부분 체결은 체결률 분자에 포함하고 체결 수량률과 잔량을 별도로 기록한다.

## 3. 지표와 종료

- **주 지표** — 시장별로 성숙한 관측 가능 짝의 `B − A` 순손익률 평균을 계산한다. 다리 손익률 분모는 공통 예약액 `C`다. 진입일 다음 다섯 번째 정규장 종가에 남은 체결 수량을 평가하고 이전 양성 청산 체결분은 실현 금액으로 합산한다. 체결이 입증된 주식의 매입 현금과 모든 적용 비용을 차감한다. 확인된 0 체결의 현금 수익률은 0이다. 어느 한 다리라도 미확정이면 짝 전체를 주 지표에서 제외하며 누락률에 포함한다.
- **보조 지표** — 양성 접수와 완결 관측이 있는 DAY 주문 중 양성 체결이 1주 이상인 비율, 체결 수량/주문 수량, 체결 다리의 매입원가 기준 비용 차감 평가손익률, 체결 후 최대 불리 변동을 시장·다리별로 낸다. 최대 불리 변동은 각 체결가 대비 해당 체결 뒤에 시작해 규칙상 청산 또는 평가일 종가 전에 끝나는 완결 정규장 1분봉 저가의 최대 하락률(최소 0)을 체결수량 가중 평균한다. 시각·봉 커버리지 누락은 해당 지표 `UNKNOWN`이다. 체결 시각이 관측 시각으로만 근사된 경우 최대 불리 변동에서 제외하고 별도 집계한다.
- **비용** — 원장에 검증된 수수료·세금을 우선 사용한다. 모의 수수료가 누락되거나 0이 실제 부담을 대표하지 않는 항목과 평가 청산에는 봉인 시 버전·해시로 고정한 시장별 공통 비용표를 적용한다. 수량·거래 금액·매수/매도 방향별 요율, 세금, 최소 수수료, 반올림을 명시한다. 실제 체결가에 이미 반영된 슬리피지를 다시 차감하지 않는다. 비용표 또는 필수 가격·종료 증거가 없거나 기업행동 조정 계약이 없으면 결과는 `UNKNOWN`이다.
- **제출 차단** — 후보→등록→전송 차단→브로커 거절→접수→부분/전체 체결·검증된 무체결·미확정의 건수 및 분모를 공개한다. 원래 결정의 `retro/v1 retro_decisions`와 `block_reason`을 원본 의사결정 맥락으로 보존하고, 모의 각 다리의 차단 코드와 별도 필드에 둔다. 누락과 제출 지연을 집계하고 원인을 서로 대입하지 않는다.
- **종료** — 두 시장의 계좌 준비 확인 뒤 봉인한다. 봉인 시 두 달력의 시작·끝 날짜를 고정하고 시장별 40개 정규장 동안 제출한다. 마지막 의사결정의 대상 세션까지 포함하도록 끝나는 날의 신규 결정 마감은 전일 장 종료로 두며, 마지막 체결 세션 뒤 5개 정규장을 평가에 사용한다. 시간 연장은 없다. 40개 세션 뒤 전 짝의 평가 시한이 지난 후 한 번 채점한다. 시장별 관측 가능 성숙 짝 50개 미만은 `INSUFFICIENT_SAMPLE`, 성숙 짝 관측 불가율이 10% 초과면 `UNVERIFIED`다. 시장별 지표를 나란히 보고 두 시장 모두 요건과 효과 기준을 통과할 때만 가설 지지로 기록한다. 표본 문턱이나 효과 기준은 통계 검정력·유의성을 뜻하지 않는다.
- **중단** — 계좌 불일치, 실계좌 도달 위험, 귀속 누락, 중복 송신·예약 불일치가 발견되면 신규 진입을 중지하고 기존 대사·청산 계약을 적용한다. 재개로 시험 창을 연장하지 않는다. 봉인 전에는 미래 시험 행을 읽지 않는다. 중간에는 안전·대사만 확인하고 비교 지표를 읽거나 결과에 따라 필터·청산·가격·표본 규칙을 바꾸지 않는다. 최종 1회 열람은 ROB-1429의 `test_looks`와 `k` 규칙을 따른다. 모의 결과에서 실계좌 정책으로의 자동 승격은 없다.

권한 있는 운영자가 후속 구현을 승인한 뒤 기존 세션 또는 수동 CLI를 foreground로 시작한다. 예상 계좌 fingerprint, 모의 endpoint, 환경 게이트 기본 off, 호출별 명시 확인, 기존 cap·귀속 실패 차단을 모두 유지한다. KIS 미러는 기존 경로의 결정별 BUY 계획·검증·귀속을 재사용한다. 보고서 전체 도구는 WATCH와 SELL도 계획하므로 실험 주문의 실행 진입점으로 쓰지 않는다. 기존 보고서 래퍼는 `confirm`을 검사하고 내부 주문 구현을 직접 호출한다. 후속 진입점에서 기존 `KIS_MOCK_ENABLED` 설정 검증과 예상 모의 fingerprint를 명시적으로 요구하고, 단일 BUY 선택·공통 수량·DAY 범위·연결 증거를 입증해야 한다. 신규 스케줄·자동 실행, ROB-1301 shadow 배선 또는 live 주문 연결을 추가하지 않는다.

짝·다리 상태, 결정/제안/보고서/예약/주문 키, 수신 시각·가격, 예상 계좌 fingerprint 확인 결과, 원본·모의 차단 코드, 대사 커버리지는 후속 구현의 비공개 실험 기록에 저장한다. 주문·귀속·체결의 정본은 기존 서비스 레저다. `execution_ledger`를 읽을 때는 `execution_ledger_in_effect()`를 적용한다. 계좌번호·자격 증명과 원본 응답은 커밋하지 않는다. 채점 산출물은 등록된 manifest 해시와 함께 ROB-1429 보고서 위치에 둔다.

## 5. 위험과 KIS 미러 0건 확인

각 시장에서 가격 규칙과 브로커가 고정 결합되어 있다. 모의 체결 엔진의 호가 대기열·유동성·부분 체결·지연·가격 개선 차이가 효과에 섞이므로 두 배정의 운용 결과로 해석한다. 가격 규칙 단독의 인과효과나 실체결률을 추정하지 않는다. XKRX/Asia-Seoul, XNYS/America-New_York의 휴장·조기 종료·미국 DST와 브로커별 주문 세션을 봉인 전에 확인한다. 시가와 정규장 시각은 시장별 하나의 고정 데이터 소스·달력을 양쪽에 적용한다.

브리프에 보고된 30일 미러 0건의 운영 원인은 **미확인**이다. 저장소에서는 보고서 단위 명시 호출과 기본 `dry_run=True`를 확인했다. 실전송 모드는 `confirm=True`가 필요하며, 계획기는 비대상 시장·종목, 가격/수량 누락 등을 제외한다. 이 경로는 이미 미러된 `report_item_uuid`를 건너뛴다. 저장소에서 찾은 호출자는 수동 MCP 도구 하나다. 2026-09-03 도구 사용 감사에서 직전 30일 호출 0건이 확인되지만, 11월 창의 호출 여부는 이 자료로 판단할 수 없다. hk 5624 댓글 28198은 후보 로그와 결정 근거의 범위를 확인했으며 미러 호출·전송 자료를 담고 있지 않다.
