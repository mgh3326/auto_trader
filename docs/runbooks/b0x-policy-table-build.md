# B0X policy-table source playbook

This source queues one market-scoped policy-table build. It does not create a
trading cycle or grant order authority. The installer must supply the exact
isolated operator checkout, Git write identity/source, and existing credential
source. The builder emits one machine-readable `BUILD_OUTPUT_JSON` manifest;
the Prefect receipt binds the auto_trader and operator HEADs, exact generated
filenames, and each generated byte/symlink hash. Staging accepts only the
receipt paths in that same checkout. Cross-checkout output, pre-existing or
post-build same-market contamination, artifact drift, and symlink escape fail
before a Git write.

KR owns only the KR policy-table paths. US owns only the US paths. The crypto
slot worker remains the sole owner of `latest-crypto.json`; Prefect invokes the
crypto builder with `--preserve-latest-pointer`, so it does not read, replace,
remove, or stage that path. Missed ticks are preserved as unconsumed evidence
and are never caught up implicitly.
